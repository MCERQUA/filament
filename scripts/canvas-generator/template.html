// Protocol Stack

4 layers, each independently usable. Higher layers build on lower ones.

L3
Active Coordination
mesh-queue · mesh-jobs · mesh-semaphore · mesh-pipeline
Parallel work claim, locks, multi-step pipelines
L2
Events & Broadcast
mesh-event · mesh-chat · BROADCAST/ · BLACKBOARD/
Pub/sub fanout, persistent topic history, group chat transport
L1
Direct Messaging
mesh-send · mesh-recv · mesh-ack · inbox/ · sent/ · DEAD_LETTER/
Point-to-point messages, atomic mkdir-claim delivery, quarantine
L0
Liveness
STATE_CHECK/ · HEARTBEAT/ · REGISTRY/
Agent presence, heartbeat stamps, registry, watchdog integration

Design Principles

  • > Files are the bus. No broker, no DB. Every primitive is a POSIX file.
  • > Atomic mkdir claims. Race-free slot allocation.
  • > Additive only. No file deleted by protocol. TTL + archive handle retention.
  • > inotify trigger. Watchdog fires consumers in near-real-time.
  • > EROFS from agents. Agents only write to mounted paths. Host owns shared-dir creation.
